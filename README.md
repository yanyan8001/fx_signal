# FXシグナル通知(アプリを閉じていても届く版)

テクニカル指標でFXのシグナルを判定し、スマホへプッシュ通知するアプリです。

- **アプリ(index.html)**: GitHub Pagesで公開するPWA。画面表示、設定、プッシュ通知の準備を担当します。
- **サーバー側(server/ と .github/)**: GitHub Actionsが15分ごとにレートを取得し、新しいシグナルだけをスマホへ送ります。サーバーを借りる必要はなく、無料です。

## セットアップ(はじめの1回)

### 1. GitHub Pagesで公開する

1. GitHubで新しいリポジトリを作ります(例: `fx-signal`、**Public**)。
2. zipを展開し、**中身をすべて**(フォルダを含めて)リポジトリにアップロードします。
   - 「Add file → Upload files」にフォルダごとドラッグします。
   - `.github` フォルダが上がらないときは、「Add file → Create new file」で名前欄に `.github/workflows/check.yml` と入力し、同名ファイルの中身を貼り付けます。
3. **Settings → Pages** で Source を「Deploy from a branch」、Branch を `main` / `(root)` にして保存します。
4. 1〜2分後に `https://ユーザー名.github.io/fx-signal/` で開けます。

### 2. アプリでプッシュ通知を準備する

1. スマホで公開URLを開きます。iPhoneは、Safariの共有ボタンから「ホーム画面に追加」して、そのアプリから開きます(iOS 16.4以降)。
2. 設定タブの「データ」で、Twelve Dataの無料APIキー(twelvedata.com)を入れて「ライブ」を選びます。
3. 通貨ペア、指標、必要な強度を好みに合わせます。
4. 「閉じていても通知(サーバー連携)」の **プッシュ通知を準備する** を押し、通知を許可します。
5. 表示された文字列の **コピー** を押します。

### 3. GitHubに登録する

1. リポジトリの **Settings → Secrets and variables → Actions → New repository secret** を開きます。
2. Name に `FX_CONFIG`、Secret に先ほどコピーした文字列を貼って保存します。
3. リポジトリの **Actions** タブを開き、無効と表示されていたら有効にします。

### 4. テスト通知で確認する

**Actions → FXシグナル確認 → Run workflow** で「テスト通知だけ送る」にチェックを入れて実行します。1分ほどでスマホに「テスト通知」が届けば完了です。

これ以降は、月〜金に15分ごとに自動で確認します。

## 動き方

- 最初の実行では、その時点で出ているシグナルは通知せず記録だけします(古いシグナルの通知を避けるため)。
- 同じ足に出た同じシグナルは1回しか通知しません。
- 市場が閉じていて最新の足が古いときは、判定しません。
- 通知を送れなかったときは、次の実行でもう一度送ります。
- 通知を送れない状態(購読の失効など)や、全通貨ペアでレートを取れない状態のときは、実行が失敗として記録され、GitHubからメールが届きます。

## 設定を変えたとき

通貨ペア、時間足、指標、必要な強度を変えたら、アプリの文字列をコピーし直して、Secret `FX_CONFIG` を更新してください。サーバーは Secret の内容で動きます。

## 知っておいてほしいこと

- **確認の間隔**は `.github/workflows/check.yml` の `cron` で決まります(初期値は15分ごと)。アプリ内の「チェック間隔」は、画面を開いているときだけに効きます。
- GitHubの定期実行は、数分から数十分遅れることがあります。直近3本の足で判定する初期設定なら、多少の遅れで取りこぼしにくくなっています。
- Twelve Dataの無料枠は1日800リクエストです。3ペアを15分ごと(月〜金)に確認すると1日約288回です。ペアを増やす場合は、4時間足なら `cron` を1時間おきにするなど、間隔を空けてください。
- 公開リポジトリで60日間まったく更新がないと、GitHubが定期実行を止めます。止まったら Actions タブから再開できます。
- `FX_CONFIG` にはAPIキーとプッシュ用の秘密鍵が入っています。GitHubのSecret以外には貼らないでください。リポジトリがPublicでも、Secretの中身は公開されません。実行ログにもAPIキーや購読先は出ません。
- 端末のブラウザデータを消した、アプリを入れ直した、通知を一度オフにした、などのときは、手順2からやり直して `FX_CONFIG` を更新します。
- シグナルは機械的な判定です。投資の助言ではありません。

## ファイル

| ファイル | 役割 |
|---|---|
| `index.html` | アプリ本体 |
| `sw.js` | 通知の受信、オフライン用キャッシュ |
| `manifest.webmanifest`, `icon-*.png` | ホーム画面に追加するための設定とアイコン |
| `server/check.mjs` | 確認と通知を行うスクリプト |
| `server/core.cjs` | アプリと同じ判定ロジック(`index.html` から写したもの) |
| `.github/workflows/check.yml` | 15分ごとに実行する設定 |
| `package.json` | サーバー側が使うライブラリ(web-push) |
